# Análisis exploratorio de expresión génica con R

## Descripción

Proyecto académico individual destinado a organizar un análisis exploratorio de datos de expresión génica con R y practicar el control de versiones mediante GitHub.

El repositorio contiene la estructura inicial del proyecto. El análisis todavía no se ha implementado.

## Objetivos

- Organizar los datos, el código y los resultados en carpetas.
- Explorar la distribución de los valores de expresión génica.
- Generar tablas y gráficos para describir los datos.
- Registrar los cambios mediante commits claros y descriptivos.

## Organización del repositorio

- `datos/`: datos de entrada y descripción de su organización.
- `scripts/`: código de R. Contiene el archivo inicial `analisis.R`.
- `resultados/`: tablas y figuras generadas por el análisis.
- `README.md`: presentación e instrucciones del proyecto.
- `LICENSE`: licencia MIT.
- `.gitignore`: archivos que se excluyen del control de versiones.

## Requisitos

- R.
- RStudio como entorno de trabajo opcional.

## Instrucciones de uso

1. Descargar el repositorio desde Code > Download ZIP y descomprimirlo.
2. Incorporar en `datos/` una tabla de expresión génica con genes en las filas y muestras en las columnas.
3. Abrir `scripts/analisis.R` en R o RStudio.
4. Incorporar el código de importación y análisis, adaptándolo al formato de los datos.
5. Guardar las tablas y figuras generadas en `resultados/`.

El archivo actual `analisis.R` contiene únicamente comentarios iniciales y todavía no genera resultados.

## Control de versiones

Los cambios del proyecto se registran mediante commits con mensajes que describen las modificaciones realizadas.
